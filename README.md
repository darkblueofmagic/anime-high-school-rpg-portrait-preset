# ⚙️ How to Install
1. [REQUIRED] Install Claudia's [Dungeon Extension v2](https://github.com/clauds-clauds/ai-dungeon-browser-extension-v2)
2. Save the `Japan_adventure (1).json` file below
3. Launch your current [🏫 Anime High School RPG](https://play.aidungeon.com/scenario/5QtD39ZnBgRl/anime-high-school-rpg?share=true&unlisted=true) adventure
4. Press the top left button, select the new Editor option, and import `Japan_adventure (1).json` using Adventurer Picker
5. Enjoy!
