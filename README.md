# 🏫 Anime High School Life: Portrait Preset [Ver 0.5]
IMPORTANT: The latest AI Dungeon update no longer works with Claudia's original Dungeon Extension v2. However, Mahesvara/Oratorian on Discord has created a Resurrected version (Mozilla Firefox fully supported; Chrome version exists, but you'll have to manually get the file from the Dungeon Extension v2 Discord thread in the link below).

Experimental: This Portrait Preset is still in its initial stage, expect future updates and changes!

# ⚙️ How to Install (Mozilla Firefox only)
🖥️PC | 📱Android:
1. [REQUIRED] Install Mahesvara/Oratorian's [Dungeon Extension v2 Resurrected](https://addons.mozilla.org/en-US/firefox/addon/dungeonextensionv2resurrect/)
2. Download the most recent `.json` portrait preset file in [Release](https://github.com/darkblueofmagic/anime-high-school-rpg-portrait-preset/releases)
3. Launch your current [🏫 Anime High School Life](https://play.aidungeon.com/scenario/um1bdeFcKkTH/anime-high-school-rpg?share=true&published=true) adventure
4. Press the top left menu button, select the new Editor option, and import the `.json` file using Adventurer Picker
5. Enjoy!

Note for Android: If you can't install at step #1, tap ⋮ and enable desktop site. You can disable it later at step #5.
